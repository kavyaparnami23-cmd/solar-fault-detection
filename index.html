How It Works

A four-step closed-loop system from sensing to automated action.

// STEP 01
Sensor Collection
ESP32 reads temperature, humidity, and panel voltage and uploads to ThingSpeak IoT cloud in real-time.
// STEP 02
AI Image Analysis
ESP32-CAM captures panel images. EfficientNet TFLite classifies: Clean, Dust, or Crack with confidence scores.
// STEP 03
Decision & Action
Dust → cleaning motor fires. Crack → GitHub issue raised for immediate inspection and maintenance.
// STEP 04
Dashboard Reporting
All data, predictions and alerts visualised in real-time with live graphs, gauges and a notification log.

About the Project

An AI-powered IoT system for real-time solar panel health monitoring, automated fault detection, and self-cleaning. Combining embedded systems, deep learning, and cloud computing to maximise solar energy efficiency.

🎯 Project Objective

Develop a smart, automated solar panel monitoring system that detects faults like dust and cracks using AI, and takes corrective action — reducing downtime and maximising energy output.

🤖 AI Model

EfficientNet-based CNN trained on thousands of solar panel images, converted to TFLite for fast edge inference. Classifies panels into three states: Clean, Dusty, and Cracked.

📱 IoT Architecture

ESP32 reads sensor data and transmits to ThingSpeak cloud. ESP32-CAM captures images for AI analysis. Motor control for automated cleaning via ThingSpeak write API.

🌐 Web Dashboard

Responsive real-time dashboard built with HTML, CSS, JavaScript, and Flask. Displays live sensor data, ThingSpeak graphs, AI predictions, and smart alert log.
